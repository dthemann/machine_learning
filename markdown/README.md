mathematics, code, printed output, tables and figures, in plain Markdown. They render on
GitHub and in the VS Code Markdown preview (maths included). To change a parameter and see
what happens, run the notebook itself.

Figures live in `figures/<notebook>/`. Reading the raw Markdown, you will meet three things
that are there for GitHub's sake, where Markdown is parsed before the maths: ``$`…`$`` around
formulas that contain Markdown characters (GitHub's syntax for verbatim maths), ```` ```math ````
blocks for displayed equations, and an empty `<span></span>` where a formula touches a letter
or a punctuation mark, as in `$k$<span></span>NN`. All three render as ordinary maths.

Everything here is generated by `nb2md.py` from the notebooks' last saved run, so after editing
or re-running a notebook, regenerate from the course folder:

```bash
python markdown/nb2md.py                                    # every notebook
python markdown/nb2md.py notebooks/09_decision_trees.ipynb  # just the ones named
```
